# 日和 · 每日计划与日记

双击 `日和.exe`，或者打开桌面上的「日和 · 每日计划与日记」快捷方式，就可以开始记录。

这是 Windows 64 位桌面软件。当前电脑已经具备运行环境，不需要再安装开发工具。请把 `日和.exe`、三个 DLL 文件和 `ui` 文件夹放在一起；移动时，把整个「日和」文件夹一起移动。

## 每天怎么用

1. 在「今天，想做些什么？」里输入计划，按 Enter 或点击「添加」。
2. 点击复选框标记完成；直接点击计划文字修改。鼠标移到计划上，会出现上移、下移和删除按钮。
3. 拖动计划左侧的小点调整顺序。也可以用 Tab 选中小点，再按 Alt + 上下方向键移动。
4. 点击一个人物表情选择心情，再点一次可以取消。五种心情依次是开心、还不错、普通、有点低落、很累；历史页也显示对应表情。
5. 在日记里写下几句话。支持换行，输入后自动保存，不需要找保存按钮。

删除计划后，页面会短暂显示「撤销」，8 秒内可以恢复。

右上角显示「已保存到本机」时，修改已经保存。如果显示保存失败，请先到设置里导出一份备份。日记字数不统计空格和换行；表情按 Unicode 码点计数。

## 翻看以前的日子

「历史」按日期从近到远显示。点击任意一条，可以继续查看和编辑当天的计划、心情与日记。

「日历」直接显示每天的计划状态：✓ 全部完成、◐ 部分完成、× 过去日期有计划但一项都没完成。今天和未来零完成显示短横线，表示待开始；只有日记或心情的日期显示小圆点，没有记录的日期留空。每个有计划的日期还显示完成数。

点击日期即可打开；只浏览一个空日期，不会增加历史记录。今天尚未做完的计划不会提前被标记为未完成。

每天的内容独立保存，未完成计划不会自动复制到第二天。跨午夜时，正在编辑的页面保留在原日期，软件会提醒你点击底部「今天」打开新的一天，避免把没写完的日记归错日期。

## 调整外观与备份

今天页使用清夏的浅绿插画和奶白纸张，人物发丝跨过纸张上沿。宽窗口把计划与日记并排放在同一页，窄窗口改为上下排列。日历以月历纸为主。历史页的两位人物沿左侧展开，大窗口中可见部分约占三分之一屏宽，左侧飘带和衣摆适当裁切，发丝和衣摆跨过记录纸页的边缘。记录按月份排列；窄窗口会收拢人物，给文字留出空间。今晚使用铺满窗口的蓝色夜景，活动卡和导航采用较暗的雾蓝配色。大窗口的操作区向中间展开，文字和按钮随之放大。设置页保留清晰的选项。

日期下面每天显示一句文学或诗歌原文，不另加栏目标签。句库共 300 条：182 条中文、118 条英文，包括《卡拉马佐夫兄弟》《瓦尔登湖》《小妇人》及古典诗词。句子按打乱后的顺序随日期变化，同一天刷新或重开保持不变，连续 300 天不重复。作者和作品显示在句子下方，鼠标停留可查看出处链接；全部内容随软件保存，使用时不需要联网。中文保留源文本字形，其中有繁体字。具体出处见 `ui/QUOTE_SOURCES.md`。

切页时画面淡出、淡入，人物不随鼠标移动。光影、星点和前景草有轻微动态，输入文字时暂停。壁纸主素材已经转换成本地高清图片，软件不需要同时运行 Wallpaper Engine。原壁纸里的全部特效没有原样搬入，界面使用更轻的光影和草叶动画。

「设置」提供深色模式、完成进度和每日一句开关。设置会随记录一起保存。动画会跟随 Windows 的“减少动画”偏好。

点击「导出数据」，选择位置保存 JSON 备份。备份包含所有日期的计划、日记、心情、设置，以及自己添加的晚间活动，可以在另一台电脑上的日和中导入。

点击「导入数据」，选择日和导出的 JSON 文件。软件先检查格式，再显示记录天数。确认恢复后，备份会替换当前的全部记录、设置和自定义活动，不会自动合并两份数据。文件上限为 16 MB。旧版备份仍可使用，其中没有自定义活动时，这份列表为空。

导入前，当前数据会另存为 `before-import-日期时间.json`。取消导入或选择错误文件，不会修改当前记录。

## 今晚做什么

底部「今晚」页沿用原软件的 8 个分类、252 件活动。场景铺满软件内容窗口，整页不向下滚动，Windows 标题栏和底部导航保留。较矮窗口会调整面板排列；长内容可在面板内部滚动，按钮仍能操作。其他页面保留正常滚动。先选分类、时间和精力，再点击「抽一个活动」。不喜欢就换一个；有多个候选时，不会连续抽到同一件事。

「加入今日计划」把活动名称和时长写入今天，即使刚才打开的是以前的记录，也不会写错日期。同名同时间的活动不会重复加入。

点击「添加自己的活动」会打开弹窗，可以填写名称、分类、时长、精力和说明，保存后进入同一个抽签池。按 Esc 或关闭弹窗会保留这次填写的草稿，成功保存后清空；保存失败时可以直接重试。自定义活动保存在本机，也随备份导出。原「今晚做什么」软件的文件、快捷方式和浏览器数据均保留；旧浏览器里的自定义活动不会自动迁入日和。

## 记录保存在什么地方

正式版数据目录是：

```text
%LOCALAPPDATA%\HiyoriDiary
```

在文件资源管理器的地址栏输入这段路径即可打开；设置页也显示实际目录。

| 文件                   | 用途                             |
| ---------------------- | -------------------------------- |
| `data.json`            | 当前记录                         |
| `previous.json`        | 上一次本地保存的备份             |
| `before-import-*.json` | 导入新备份前保留的数据           |
| `WebView` 文件夹       | 界面运行缓存，含一份本机记录缓存 |

每次保存先写临时文件，再替换当前文件。启动时会检查当前记录、本机缓存和上一份备份，使用其中最新的有效记录。如果所有副本都无法读取，软件会停止写入并提供「从备份恢复」，保留原文件。

数据保存在本机，文件没有加密。软件没有账号、服务器或云同步；换电脑前请自行导出备份。删除软件文件夹不会同时删除上述数据目录。

## 换位置或换电脑

移动软件后，可以在新的文件夹里运行 `创建桌面快捷方式.ps1`，重新生成快捷方式。若只是当前电脑日常使用，直接使用已经创建的快捷方式即可。

在其他电脑运行需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)获取 WebView2 Runtime。本次只在当前电脑实际验证过，没有测试其他机器。

## 想看懂代码，从这里开始

界面使用普通 HTML、CSS 和 JavaScript，没有 React、Vue 或前端构建流程。Windows 窗口用少量 C# 承载界面和读写文件。

| 文件                        | 负责什么                                   |
| --------------------------- | ------------------------------------------ |
| `ui/index.html`             | 顶部、页面容器、底部导航                   |
| `ui/style.css`              | 基础组件样式与交互反馈                     |
| `ui/journal.css`            | 分层场景与纸张布局、各页构图、深色模式和动画 |
| `ui/refinements.css`        | 长句排版与历史人物布局                     |
| `ui/tonight-viewport.css`   | 今晚铺满窗口、紧凑面板与活动弹窗           |
| `ui/quotes.js`              | 按日期选择句子，同一天保持不变             |
| `ui/quotes-zh.js`、`ui/quotes-en.js` | 中英文原句、作者与作品出处          |
| `ui/QUOTE_SOURCES.md`       | 句库原文来源                              |
| `ui/ui-effects.js`          | 导航移动、点击与输入时的视觉反馈           |
| `ui/assets/SOURCES.md`      | 插画来源与版权署名                         |
| `ui/app.js`                 | 页面切换、选择日期、连接各组件             |
| `ui/model.js`               | 数据结构、日期、排序、备份校验             |
| `ui/storage.js`             | 自动保存，以及界面与桌面窗口之间的通信     |
| `ui/components/tasks.js`    | 今日计划                                   |
| `ui/components/diary.js`    | 日记输入和字数                             |
| `ui/components/mood.js`     | 心情选择                                   |
| `ui/components/history.js`  | 历史记录                                   |
| `ui/components/calendar.js` | 月历                                       |
| `ui/components/day-status.js` | 日历和历史共用的每日完成状态             |
| `ui/components/tonight.js`  | 晚间抽签、筛选与自定义活动                  |
| `ui/activities.js`         | 活动数据、筛选、抽选和自定义活动校验        |
| `ui/components/settings.js` | 设置、导入导出                             |
| `source/Program.cs`         | Windows 窗口、本地文件和文件选择对话框     |

可以先看 `model.js` 中的 `newBook()` 和 `newDay()`：一本记录本按日期存放，每一天包含 `tasks`、`diary`、`mood`。再看 `tasks.js`，理解“用户点击 → 修改数据 → 自动保存 → 更新页面”的过程。

修改界面文件后，关闭并重新打开软件就能看到变化。修改 C# 后，在 PowerShell 中运行：

```powershell
.\source\build.ps1
```

编译前先关闭日和。编译使用 Windows 自带的 .NET Framework 编译器和随软件附带的 WebView2 DLL。

如果已安装 Node.js，可以在软件文件夹中运行数据逻辑测试：

```powershell
node --test tests/*.test.js
```

实现参考：[Microsoft WebView2 WinForms 文档](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.winforms.webview2)、[本地内容加载说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/working-with-local-content)。WebView2 组件版本为 1.0.2535.41，原始许可和声明保存在 `licenses` 文件夹中。
