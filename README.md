# 日和 一款日历日记待办软件
日和是一款 Windows 桌面计划与日记软件，可以记录每日待办、心情和日记，通过日历与历史页面回顾生活，也能在「今晚」页面抽取活动，找点想做的事。界面搭配插画和轻柔动画，记录自动保存在本机，支持导入、导出备份，无需注册账号。
